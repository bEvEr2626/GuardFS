# FileGuard (GuardFS)

Многопоточный демон для фонового контроля целостности файлов в пользовательском файловом пространстве.

## Возможности

- Мониторинг пользовательского перечня файлов и каталогов.
- Хеширование файлов по SHA-256 (OpenSSL EVP).
- Периодическое сканирование с настраиваемым интервалом.
- Логирование изменений контрольной суммы в `fileguard.log`.
- Автообновление эталонной контрольной суммы для выбранных записей.
- Многопоточное вычисление хешей (`std::jthread`).
- Встроенное исключение служебного каталога SonarLint (`~/.sonarlint`) из мониторинга.
- Корректная остановка по `SIGINT`/`SIGTERM`.

## Формат списка целей

Файл по умолчанию: `fileguard.targets`

Формат строки:

```text
path|recursive|auto_update
```

Где:
- `path` — путь к файлу или каталогу (`~` поддерживается)
- `recursive` — `0/1` (для каталогов)
- `auto_update` — `0/1` (обновлять ли сохраненную КС при изменении)

Комментарии начинаются с `#`.

Пример:

```text
~/.bashrc|0|1
~/.config|1|1
~/.local|1|1
/etc|1|0
```

## Сборка

Требования:
- компилятор с поддержкой C++23
- OpenSSL dev-пакет (libcrypto)

```bash
make
```

## Запуск

Один проход сканирования:

```bash
./guardfs --once
```

Демон (по умолчанию интервал 5 секунд):

```bash
./guardfs
```

С параметрами:

```bash
./guardfs --interval 10 --targets fileguard.targets --hash-db fileguard.hashes --log fileguard.log
```

Остановка: `Ctrl+C` или `kill` (SIGTERM).

## Файлы данных

- `fileguard.targets` — редактируемый пользователем список мониторинга.
- `fileguard.hashes` — база эталонных SHA-256 (создается/обновляется автоматически).
- `fileguard.log` — журнал событий.
